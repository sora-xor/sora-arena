# Localhost P2P evidence transport research

`arena_core::localhost_transport` exchanges signed evidence over real UDP sockets bound to loopback addresses. It only accepts an **offline admission** (zero XOR bond) and one exact, pre-admitted peer address. Both peers must already have the same authenticated `Context`, `Config`, ordered participant roster, and separate `DurableSession` journals.

The initiator sends an Ed25519-signed ephemeral X25519 offer. The responder verifies it and syncs the accepted offer into its evidence journal, then syncs a receipt file before sending its signed answer. Each peer derives separate directional AEAD keys. Subsequent `WireFrame` certificates, individual reveals, and checkpoints are signed, encrypted, fragmented into at-most-1,200-byte datagrams, reassembled, authenticated, and journaled before `receive()` returns. `prepare()` journals local evidence and persists its receipt before making a retransmittable datagram set; `transmit()` can resend those exact bytes after a timeout. Re-sealing the same sequence is disallowed.

`ReceiptFiles` writes one synced file per journal receipt outside the journal. This is a **test harness artifact**, not an independently trusted rollback anchor: a party able to roll back both files can still hide a complete suffix. Before a real reconnect, an independent peer or ledger must supply the latest trusted receipt to `DurableSession::restore`. The transport never restores an old AEAD channel; it requires a new handshake and fresh keys. A persistence failure closes the transport handle before it sends or returns evidence.

The focused tests exercise a two-peer certificate/reveal exchange through loopback UDP, a dropped datagram followed by byte-identical retransmission, out-of-order and duplicate fragments for a twelve-participant certificate, and failure to persist an external receipt. This slice has no acknowledgements, automatic retransmission scheduler, NAT traversal, peer discovery, deadline consensus, execution proof, or ledger settlement. Real-value admission remains disabled until the full proof and validator qualification gates pass.
