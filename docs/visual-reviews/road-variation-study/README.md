# Estate road scan-variation study — visual gate pending

The first [integrated gravel and inset-stone candidate](../integrated-roji/README.md) failed the fixed-camera Mac art gate: bright gravel and sharp polygon stone perimeters were conspicuous at player height. It remains source-only.

This second, unplaced ArtReview material keeps the original, hash-pinned [Poly Haven Grey Stone Path](https://polyhaven.com/a/grey_stone_path) photograph and its matched albedo, DirectX normal, ARM, and displacement maps. The photographed dirt, moss, weathered stone faces, and buried edges therefore remain coherent. `scripts/unreal/import_nyaagyu_road_variation_art_review.py` connects the pinned UE 5.8 `TextureVariation` function to 180 cm world-space UVs, uses its height-guided shifted UVs for every map, passes clean derivatives to the texture samples, and uses `TextureVariation_RotateNormals` for tangent-space consistency. Its material is imported under `/Game/Generated/Environment/ArtReview/RojiTextureVariation` without changing the main terrain palette or WorldBuilder.

The importer and actual function pin signatures were checked in an isolated UE 5.8.3 temporary project. Import completed with `NYAAGYU_ROAD_VARIATION_ART_REVIEW_IMPORTED`. This is **structural validation only**; a null-RHI commandlet cannot establish Mac appearance, shader compile for the packaged Metal target, repetition at the Estate entrance, close contact quality, or cost. The release project remains pinned to UE 5.8.2.

Before any main runtime placement, run the same packaged Mac build twice with only a diagnostic material switch, capture the fixed Estate entrance and player-height downward road views at identical camera transforms, inspect both images at native resolution, and compare representative 1080p frame times. A more varied material still fails if it shows quilting/dither seams, directionally inconsistent normals, recognizable repeated stone clusters, poor soil transition, or excessive GPU cost. Keep the main road unchanged unless both views improve.
